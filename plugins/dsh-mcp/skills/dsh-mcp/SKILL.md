# 使用 DSH MCP

根据用户目标确定需要 DSH 完成的操作，沿用已确认的项目目录、会话、模型与任务要求。结合现有会话的用途和上下文，选择继续会话或创建会话。

以当前 MCP 工具说明为准选择工具、填写参数并理解返回状态。

开始新的 DSH 任务前，查询可用模型，通过宿主的同步提问工具确认供应商、模型与思考程度，再配置并发送任务。当前任务中用户已明确指定或确认的选择直接沿用；已有会话的配置作为提问时的候选值。宿主没有同步提问工具时，用文字询问并等待回答。

将工作交由 DSH 执行后，通常在其返回结果后核对产出。等待期间有已明确的独立事项时，按宿主支持的方式处理，并明确涉及共享文件的写入职责；其余时间继续等待。宿主将工具调用挂起后，继续等待该调用，收到结果后按工具说明处理。

用户调整要求或 DSH 返回需要处理的问题时，结合当前任务进行协调，传达相关变化。

读取返回结果，按操作目的与完成标准核对产出及证据，处理必要的后续工作，向用户说明实际结果。
